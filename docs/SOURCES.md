# Données, unités et population

Le CSV est un dérivé du jeu Algeria Wildfire Risk publié par Abdelmalek Nedjar, sous [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Le code du producteur est sous MIT. Les attributions des données sont Open-Meteo (ERA5-Land), NASA LANCE FIRMS / ESDIS (VIIRS) et MODIS/Terra MOD13Q1 v061, NASA LP DAAC, USGS/EROS via Earth Engine. Les transformations locales comprennent les contrôles, le retrait des fuites, l’agrégation statistique et les partitions du benchmark. [Dictionnaire et attributions du producteur](https://github.com/Abdelmalek05/fire-detection-model/blob/0755f4e47f54a9e582b4f53d28f2a610098bbf1c/docs/DATASET.md)

Les cellules de 0,1° couvrent un rectangle débordant notamment sur le Maroc, la Tunisie et le sud de l’Espagne. Les observations de juin à octobre demeurent dans la population d’origine. La météo journalière comprend températures en °C, humidités en %, vitesses de vent en km/h, pluies en mm et VPD en kPa. Les cumuls et moyennes glissants sur 7 ou 30 jours portent sur le passé jusqu’à la journée observée. Les codes FWI sont des indices calculés sur des agrégats journaliers.

Dans le code producteur, la recherche dans les dates de feu retient le feu strictement antérieur à jour moins quatre jours (9999 si aucun événement). Le composite NDVI de 16 jours doit être clos avant le jour étudié. La normale est issue de 2000–2011 et l’anomalie vaut NDVI moins normale. Le CSV distribué ne contient ni les dates sources des composites ni l’historique FIRMS complet ni les observations de climatologie. Le dépôt producteur distribue un échantillon, sans manifeste associant son code de construction à l’empreinte du CSV complet local. La comparaison principale conserve donc les 24 variables historiques. L’ablation documentée utilise un sous-ensemble de ces variables.
